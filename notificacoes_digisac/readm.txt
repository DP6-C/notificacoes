# Notificações Digisac - Testes

Este repositório foi criado exclusivamente para testes internos de adaptação e validação de scripts de notificação para o Digisac.

A ideia original, a estrutura inicial e os scripts-base não são de minha autoria. Este repositório não tem a intenção de reivindicar autoria, substituir os autores originais ou se apropriar do trabalho de terceiros.

O objetivo aqui é apenas testar ajustes, compatibilidade entre navegadores, organização de versões e possíveis melhorias antes de qualquer uso definitivo.

Caso este projeto avance para uma versão oficial, os créditos, histórico e referências aos autores originais deverão ser preservados conforme apropriado.

> Aviso: repositório temporário de testes. Não reivindico autoria da ideia ou dos scripts originais.
